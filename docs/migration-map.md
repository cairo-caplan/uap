# Migration map: old per-project IP arrays → IP-centric layout

Generated by `scripts/gen_migration_map.py` from `cfg/catalog.json`.

The old data layout kept one array per project in `ips/<project>.json`
where most rows were actually *tasks* (Work Items), not IPs. The
migration split every row into (a) an independent IP in `ips/<id>.json`
and (b) a Task in `projects/<project>.json` referencing that IP. The old
array files are deleted; this page is the entry-by-entry record of that
split and of every case that still needs a human decision.

How to read a task line: the old `ips/<project>.json` entry is identified
by its `TaskId` (the `WI` and `Title` are carried over verbatim); `IPs`
lists the new `ips/*.json` documents the task references.

**Totals:** 241 IP documents, 253 tasks across 5 project files.
