ISOLA, the catalogue assistant Preview

ISOLA is an AI assistant with an MCP setup. Ask it about the IPs, projects and tasks in this catalogue and it will point you to the matching entries. It is a prototype for now, and an official integration into the platform will follow.

This is a preview of a prototype hosted outside this site, so availability and answers may change without notice. If the assistant does not load below, for example because a browser extension or a content policy blocks the frame, open it in a new tab.
